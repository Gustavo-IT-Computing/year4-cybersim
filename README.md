# CyberSim

## Overview

CyberSim is an educational cybersecurity simulation platform developed as part of the final-year Software Development Project module.

The application allows users to simulate cyber attacks and defence strategies within a controlled environment. The platform was designed to improve understanding of modern cybersecurity threats through interactive learning and scenario-based simulations.

## Features

- Malware propagation simulation
- Brute-force attack simulation
- Denial of Service (DoS) attack simulation
- Multi-attack scenarios
- Risk analysis dashboard
- Threat intelligence integration
- Defensive strategy recommendations
- Performance scoring and reporting

## Technologies Used

- Python
- Flask
- SQLite
- Matplotlib
- NetworkX

This project strengthened skills in:

- Software architecture
- Python development
- Flask web applications
- Cybersecurity concepts
